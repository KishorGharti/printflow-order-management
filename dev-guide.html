1. Platform Architecture & Security Clearance Model

The PrintFlow Developer Admin Console (accessible via /developer) is the centralized mission-control cockpit engineered exclusively for platform developers, systems engineers, and root SaaS administrators. It stands isolated above individual print shop instances, granting complete visibility, telemetry, diagnostics, and multi-tenant management across all tenant stores.

Multi-Tier Separation & RBAC Security Boundaries

Portal Path Authorized Persona Authentication Method Access Scope
/developer Platform Developers & Super Admins Developer Credentials / API Master Key Global Platform Super-Admin: DB, Servers, Backups, Tenants, Logs
/owner/login Print Shop Owners & Franchisees Store Owner Email + Password + OTP Single Tenant Store: Financials, Staff, Inventory, Pricing, Store Orders
/employee/login Reception, Designers, Finishers Store-Prefixed Employee ID + PIN/Pass Workstation Level: Reception POS, Design Kanban, Production Queue
🛡️ Security Guardrail: Client Intrusion Prevention
Situation: A curious print shop owner or employee discovers the URL http://localhost:3000/developer and attempts to view raw databases or modify other tenants' plans.
How it works: The backend middleware requireDeveloperAccess strictly validates the incoming JWT payload against the role table. If the role is owner, reception, or designer, the request is instantly rejected with HTTP 403 Forbidden: "Access denied. This endpoint is strictly restricted to SUPER_ADMIN / DEVELOPER." The developer console never leaks tenant data across portal borders.

2. Module 1: API & Server Status (ServerStatusView)

Real-time Node.js process telemetry, memory health, rate-limiting counters, and live log stream interceptors.

Key Features & Telemetry Gauges

  • API / Backend Process Status: Displays API Port (3001), Web Portal Proxy Port (3000), Active Node Version (v22.18.0), OS Architecture (win32 x64), Process PID, and running uptime.
  • Memory Footprint & Heap Monitor: Gauges Heap Memory Used (MB), Heap Total Allocation, RSS (Resident Set Size), and a visual memory saturation bar.
  • PostgreSQL Engine Ping: Real-time latency measurement in milliseconds (e.g. 1ms Ping), active connection pool count, and idle vs. total connection pool metrics.
  • Traffic & Rate-Limiting Controller: Live counter of incoming requests per minute (req/min), total processed server hits, and blocked requests against the threshold (e.g. 500 req/min).

The 5 Real-Time Log Sub-Streams

Stream Tab What it Monitors Developer Value
Mini-Sentry Crash Traces Uncaught exceptions, unhandled Promise rejections, and runtime 500 crashes. Provides full stack traces, method/route, tenant ID, and user email with one-click resolution.
Error Logs API-level handled errors (validation failures, 400 Bad Requests, DB constraint violations). Tracks failing API endpoints, parameters, and IP addresses.
Failed Requests Any HTTP 4xx or 5xx responses with measured latency in milliseconds. Identifies slow endpoints and client integration anomalies.
Authentication Logs Login events, token refreshes, failed passwords, and session terminations. Detects brute-force credential stuffing attacks against print shops.
Recent System Activity High-level business audit events across all shops (orders booked, expenses recorded). Bird's-eye view of nationwide platform activity.

3. Module 2: Database & Data Management (DatabaseView)

PostgreSQL storage inspection, table relation metrics, automated backups, and Safe SQL Playground.

PostgreSQL Cluster Diagnostics

  • Storage Allocation: Live display of total database size (e.g. 12 MB), 21 active relational tables, and estimated cluster record count.
  • Table Storage & Index Footprint: Detailed breakdown of every Postgres table (orders, saas_clients, team_members, inventory_items, payments, etc.) showing Row Count, Table Data Size, and Index Footprint.
  • Multi-Tenant Data Consumption: Shows how many orders, customers, and total booked revenue each registered shop has generated.

Database Operations & Disaster Recovery

Download Full Backup

Generates an instantaneous full offline JSON snapshot of all database tables and downloads it to the developer's workstation.

Restore Database

Uploads an offline JSON snapshot, validating schemas and repopulating missing records in disaster recovery scenarios.

Verify & Run Migrations

Runs automated schema migration scripts, guaranteeing tables, foreign keys, and indexes are in sync with application code.

Automated Scheduled Backups (Rolling 7-Day Retention)

An automated background cron runner triggers database snapshot creation daily at midnight. The system calculates backup file age (e.g., 14h ago) and enforces a 7-day rolling disk retention policy, automatically purging snapshots older than 7 days to preserve server disk space. The developer can trigger "Run Backup Now" on-demand or click Download on any archived snapshot.

Safe SQL Query Playground & Database Inspector

A built-in interactive terminal allows developers to run diagnostic SQL queries directly against PostgreSQL without opening external tools like pgAdmin or terminal SSH.

  • Read-Only Guard: Only statements starting with SELECT, EXPLAIN, and WITH are permitted. Any destructive verbs (DROP, DELETE, UPDATE, ALTER, TRUNCATE) are strictly blocked with an explanatory error.
  • Pre-Built Presets: Instant selector with pre-written queries (e.g., Recent Clients, High-Value Orders, Active Subscriptions).
  • 100-Row Safety Cap: Appends LIMIT 100 automatically to prevent server memory exhaustion.
  • Export to CSV: One-click button to download query results as a formatted CSV spreadsheet for business intelligence and reporting.
💡 Real-World Situation: Answering an Audit Query & Revenue Verification
Situation: The platform accountant needs an immediate audit of all shops that generated over Rs. 50,000 in printing orders this month.
How Developer Works with Example:
  1. Developer opens Database / Data → scrolls to Safe SQL Playground.
  2. Types the query: 
    SELECT b.name, b.subscription_plan, COUNT(o.id) as total_orders, 
       SUM(o.final_total) as booked_revenue
FROM saas_clients b
LEFT JOIN orders o ON o.business_id = b.business_id
GROUP BY b.id, b.name, b.subscription_plan
HAVING SUM(o.final_total) > 50000
ORDER BY booked_revenue DESC;
  3. Hits Ctrl + Enter. The execution completes in 4ms.
  4. Developer clicks Export CSV and emails the generated spreadsheet to finance. Zero server restarts, zero risk of data loss.

4. Module 3: Security & Session Control (SecurityView)

Live multi-tenant session monitoring, one-click token revocation, emergency kill-switches, and brute-force defenses.

Security KPIs & Active Sessions Monitor

  • Live Active Sessions: Real-time counter of every staff member and owner currently logged in across all connected print shops.
  • Failed Login Attempts Counter: Tracks blocked authentication requests, highlighting potential password-guessing attacks.
  • Session Inspection Grid: Displays User Name, Email, Role (owner, reception, designer, printer_finishing), Tenant/Business ID, Last Activity timestamp, and status (ACTIVE, OFFLINE, REVOKED).

Emergency Revocation & Token Invalidation

Per-User Session Revocation

Clicking "Revoke" next to any user immediately terminates their JWT token and invalidates their session. The next time their browser makes an API request, they are kicked out to the login screen.

Global Emergency Kill-Switch ("Revoke All Active Sessions")

Terminates every active session across all print shops simultaneously. Used during critical security updates, credential breaches, or system-wide secret rotations.

5. Module 4: Global System Settings (SettingsView)

Centralized platform branding, maintenance mode gating, email SMTP relay, and cloud file storage.

Platform Branding & Identity

Configures the master application name (e.g. PrintFlow SaaS), custom logo URL, favicon URL, developer support email (dev@printghar.com), and 24/7 emergency contact hotline (+977-9800000000). These branding elements cascade dynamically to all client portals.

Maintenance Mode Kill-Switch

Controlled Maintenance State

When activated, storefronts, owner dashboards, and employee portals display a friendly, polished maintenance screen: "The system is undergoing scheduled maintenance. Please check back shortly." Crucially, the Developer Console remains 100% online and accessible, allowing engineers to run database migrations, patch server code, and test APIs without end-users interfering with data integrity.

Email / SMTP Relay Configuration

Configures the global transactional email pipeline:

  • SMTP Host: e.g. smtp.gmail.com (or SendGrid, Mailgun, Amazon SES).
  • SMTP Port: Standard TLS port 587 or SSL port 465.
  • Sender Email & Display Name: e.g. notifications@printghar.com → PrintFlow System.
  • Application: Powers the Owner 6-digit OTP Forgot Password recovery system, customer PDF invoice delivery, and daily automated management digests.

Subscription & License Lifecycle Management (SubscriptionModal)

Single "Standard Plan" Philosophy

PrintFlow employs a streamlined Standard Plan (All Features Included) model. Instead of complex, confusing tiered feature gates, all print shops receive full access to all features (POS, Production Kanban, Accounting, Inventory, WhatsApp integration). Monetization is strictly driven by License Duration:

Billing Duration Effective License Period Typical Use Case
Monthly 30 Days Standard recurring subscription for local print shops.
Quarterly 90 Days Seasonal printing contracts (e.g., election or festival seasons).
Yearly 365 Days Annual licensed enterprise printing presses.
Lifetime Unlimited (10 Years / Indefinite) Company-owned flagship branches (e.g., Print Ghar Main Bagbazar).

License States & The "Read-Only Order Lock" Guard

ACTIVE

More than 7 days remaining. Full unrestricted access across all portals.

GRACE PERIOD

7 or fewer days remaining. Displays non-blocking renewal reminder to store owner.

EXPIRED

Read-Only Locked. Can view past orders and print invoices, but cannot book new orders.

SUSPENDED

Immediate block. Store owner and staff logins are disabled.

Quick Extension Shortcuts

Inside the Subscription Management modal, developers have 4 one-click extension buttons: +30 Days, +90 Days, +1 Year, and Lifetime (10y). These automatically calculate and advance the expiration date without requiring manual calendar entry.
